# Noyau expérimental A3-A40

Cette archive contient le premier noyau Linux 3.18.22 recompilé, sa configuration, les révisions des sources et du compilateur, les journaux et les sommes SHA-256.

**Ce n’est pas une ROM Android 13 ni une image boot/recovery prête à flasher. Aucun essai sur tablette n’a été effectué.** Les 42 avertissements de sections restent à analyser.

Sources et recette correspondant à cette compilation : [commit 63479dc](https://github.com/arno065/romcustomA3A40/tree/63479dc12cbb693b3d85bf18e211414fac0b4fd2).

Le fichier `SHA256SUMS` placé ici contrôle l’archive ; celui à l’intérieur contrôle chacun de ses fichiers.
